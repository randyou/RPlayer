# RPlayer v0.11.4 — 命令面板淡入

## 目标

为命令面板增加与弹窗一致的轻量进入动画。

## 完成项

- 命令面板打开时 120ms 淡入：
  - 面板填充；
  - 边框；
  - 阴影；
  - 内容文字与列表。
- 关闭后重新打开会重置动画起点。
- 减少动态效果开启时直接显示。
- 键盘上下选择、Enter 执行、Esc 关闭逻辑不变。

## 验证

- Release 构建通过。
- `cargo test --release`：29 passed，0 failed。
- 实机 Ctrl+K 打开截图检查：
  - 命令标题、搜索框、快捷键提示正常；
  - 命令列表布局未变化；
  - 面板最终完全不透明。

## 暂缓

- 命令面板退出动画。
- 主题切换渐变。
- 键盘焦点环。
