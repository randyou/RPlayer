## 4. 手工验收

1. 曲库右键任一歌曲：菜单 30px 行高、图标、危险项红色、评分/歌单子菜单可用。
2. 专辑/艺术家卡片右键：菜单不遮挡窗口，操作生效。
3. 播放列表/智能歌单右键：重命名/编辑/删除对应正确对象。
4. 桌面歌词右键：滑杆、锁定、关闭可用；不抢主窗口焦点。
5. 1120×720：菜单不超出窗口，设置六页签可滚动。
6. Tab 遍历对话框：焦点不逃逸，Esc 关闭后焦点回到触发按钮。

## 5. 已知限制

- egui 子菜单宽度仍可能贴近窗口右缘；当前通过 `menu_width=280` 限制，后续可改为自绘翻转定位。
- 右键菜单暂未提供键盘快捷键打开；本次只保证鼠标打开后的行级可访问性。
