# RPlayer v2.0.5 计划：健康检查与工具内部收口

- 基线：`v2.0.4` / `03296a2`，70 tests
- 分支：`feature/v2.0.5`
- 目标：重排健康检查内部信息层级，补齐歌词编辑器标题，保持工具窗口风格一致

## 1. 范围

### P0 健康检查

- 顶部增加三张 64px 数据卡：缺失文件 / 空标签 / 重复候选。
- 数值使用 24px 衬线字体；大于 0 时使用 signal 色，0 时使用 accent 色。
- 空分类不再重复输出“分类 0”标题；无问题时只显示一条“没有发现明显问题”。
- 有内容时滚动区高度 240px；空状态压缩为 72px，减少空白。
- 底部保留“批量替换根目录”“移除失效记录”“关闭”与说明文字。

### P1 歌词编辑器

- 增加 `LYRICS EDITOR` 等宽眉题与 22px 衬线“编辑歌词”标题。
- 曲目信息保留在标题下方；时间/文本行、保存与取消逻辑不变。

### P1 智能歌单

- 智能歌单：保留 `SMART PLAYLIST` 眉题与衬线标题，规则行后增加实时匹配预览卡。
- 本版不改变规则行、匹配条件与保存逻辑。

## 2. 实现

- `src/app/health.rs`：`health_stat` 数据卡；`section` 对 0 项提前返回；空状态滚动高度压缩。
- `src/app/lyrics_edit.rs`：眉题 + 衬线标题。
- `src/app/smart.rs`：规则行后新增 `PREVIEW` 卡，实时计算匹配数量。
- 版本：`Cargo.toml` → `2.0.5`。

## 3. 验收

- 健康检查无问题时只显示三张 0 数据卡与一条正常提示，不重复分类标题。
- 健康检查有缺失/空标签/重复时，分类与行项目正常显示，滚动不裁切。
- 歌词编辑器标题为衬线，时间/文本编辑与保存行为不变。
- 智能歌单修改条件、限制或全部/任一后，预览数量同步更新。
- `cargo test --release` ≥ 70；exe metadata `2.0.5.0`。

## 4. 已知限制

- 智能歌单只增加实时预览，不新增拖拽排序或规则组嵌套。
- 桌面歌词 DComp 双击解锁限制沿用 v2.0.2。
