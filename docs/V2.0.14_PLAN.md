# RPlayer v2.0.14 — 失败态与离线出口

日期：2026-11-25
分支：`feature/v2.0.14`

## 目标

把“网络失败”变成可理解、可继续的状态，不显示原始错误文本，不阻断本地播放。

## 范围

- 离线模式页：本地可用清单、当前补全未完成提示、“本次联网/保持离线”动作。
- 在线内容页：最近一次联网失败卡，区分 404、超时、限流、离线四类。
- 失败后保留本地内容；重试只影响当前歌词请求，不改变播放或曲库。
- 失败分类在歌词请求错误处理处统一映射，设置页只负责呈现。

## 验收

- 离线模式下打开设置，能看到本地可用清单与本次补全警告。
- 手动下载歌词失败后，在线内容页出现对应失败卡与重试动作。
- 限流状态不提供立即重试，避免连续请求。
- 无失败时显示“没有待处理的失败”。
- `cargo test --release` 70 passed；设置页 1440×900 不溢出。

## 不做

- 不新增网络探测线程，不伪造 404/429。
- 不改变歌词下载协议与重试策略。
- 不重做在线内容页其余结构。
