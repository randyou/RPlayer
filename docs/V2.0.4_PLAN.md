# RPlayer v2.0.4 计划：边界状态与长文本

- 基线：`v2.0.3` / `e6d3434`，70 tests
- 分支：`feature/v2.0.4`
- 目标：补齐专辑/艺术家卡的长文本与读屏信息，验证空状态，收敛边界表现

## 1. 范围

### P0 长文本

- 专辑卡：标题与艺术家仍按格子宽度截断；悬停显示完整“专辑 / 艺术家”。
- 艺术家卡：悬停显示完整艺术家名。
- 两卡的无障碍名称包含完整标题、艺术家、专辑数与曲目数，不依赖视觉截断。

### P0 读屏

- 专辑卡：`专辑：{title} — {artist}，{n} 首`
- 艺术家卡：`艺术家：{name}，{n} 张专辑，{m} 首`
- “添加音乐”空卡：`添加音乐文件夹`

### P1 空状态

- 空专辑墙 / 空艺术家墙沿用 `browse_empty` 插图与说明。
- 空搜索、空队列、空歌词保持现有统一空状态。
- 不新增后台能力，不改变排序与分组逻辑。

## 2. 实现

- `src/app/browse.rs`：`response.on_hover_text`、`response.widget_info`。
- 不改变卡片尺寸、网格列数或点击行为。

## 3. 验收

- 长专辑名截断但悬停可读完整名称。
- AccessKit 能读出完整专辑/艺术家名称与计数。
- 空专辑 / 空艺术家显示插图说明，不出现空白区域。
- `cargo test --release` ≥ 70。
- exe metadata `2.0.4.0`。

## 4. 已知限制

- 工具窗口内部控件仍沿用 v2.0.3 布局，本版不改 EQ 频段、健康检查分区或智能歌单规则行。
- 桌面歌词 DComp 双击解锁限制沿用 v2.0.2。
