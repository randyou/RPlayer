## LYR-06 桌面歌词透明度拆分

- 拆成两个独立参数：
  - `desktop_lyrics_opacity`：面板背景不透明度（0–100%）
  - `desktop_lyrics_text_opacity`：歌词文字不透明度（0–100%）
- 窗口本身保持完全不透明，不再对整个窗口调用 `SetLayeredWindowAttributes`。
- 面板背景、描边使用面板透明度绘制；歌词、标题、阴影使用文字透明度绘制。
- 面板 0% 时只移除背景，歌词仍可见。
- 调节入口：
  - 桌面歌词左上角「透明」按钮，弹出两个滑块；
  - 桌面歌词右键菜单；
  - 设置 → 桌面歌词。
- 两个值写入 `library.json`，旧数据缺少文字透明度时默认为 100%。

## PLAY-01 五态播放模式

合并原「随机」与「循环」两个按钮为单按钮，循环切换：

1. 顺序播放
2. 列表循环
3. 单曲循环
4. 随机播放
5. 随机循环

- 图标与提示随模式变化。
- 随机模式使用洗牌袋，保证一轮内不重复。
- 随机播放：一轮结束后停止。
- 随机循环：一轮结束后重新洗牌继续。
- 队列发生变化时清空洗牌袋。
- 新增随机循环图标（交叉箭头 + 循环箭头）。
