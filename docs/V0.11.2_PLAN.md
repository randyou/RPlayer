# RPlayer v0.11.2 — 曲库行动效

## 目标

将列表 hover 过渡扩展到曲库表格行，同时保证选中行和当前播放行不闪烁。

## 完成项

- 普通歌曲行 hover 背景 120ms 淡入/淡出。
- 当前播放行保持 accent 背景与左侧指示条。
- 选中行、批量勾选行继续立即高亮，不参与 hover 动画。
- 动效受“减少动态效果”开关控制。

## 验证

- Release 构建通过。
- `cargo test --release`：29 passed，0 failed。
- 实机 hover 第二行截图检查：
  - 普通行显示浅灰 hover 背景；
  - 当前播放行保持绿色高亮；
  - 表头与首行边界未变化。

## 暂缓

- 弹窗进入/退出动画。
- 主题切换颜色渐变。
- 键盘焦点环。
