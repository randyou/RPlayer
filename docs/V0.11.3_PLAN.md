# RPlayer v0.11.3 — 弹窗淡入

## 目标

为模态弹窗增加轻量进入动画，同时不改变布局、焦点和键盘操作。

## 完成项

- 弹窗打开时 120ms 淡入：
  - 背景遮罩透明度；
  - 弹窗面板填充与边框；
  - 阴影透明度；
  - 内容整体透明度。
- `last_dialog` 在弹窗关闭时重置，同一弹窗再次打开仍会淡入。
- 减少动态效果开启时直接显示，不播放淡入。
- 弹窗布局、焦点请求和 Enter 提交逻辑未改动。

## 验证

- Release 构建通过。
- `cargo test --release`：29 passed，0 failed。
- 实机打开「编辑标签」截图检查：
  - 弹窗最终完全不透明；
  - 五个输入框仍等宽；
  - 标题、说明、按钮位置未变化。

## 暂缓
