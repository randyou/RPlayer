## 8. 与 v2 目标的差距判断

- **功能面**：v2 的承诺（本地优先、离线可用、桌面歌词、智能歌单、CUE、备份恢复）已闭环；**托盘菜单**与**迷你播放器**均已于 v2.1.0 按稿重做（证据 `v210-tray-menu-*.png`、`v210-mini-*.png`）。
- **质量面**：还差三项硬指标 —— 滚动 P95、空闲 CPU、真机 DPI；其中滚动与 CPU 是同一类问题（每帧成本 + 唤醒频率），一起做最省事。
- **流程面**：v2 收官以 `V2_REGRESSION.md` 全绿为准，不再以"53 面打完勾"为准。
- **规模面**：10k 可用，5 万首与输出设备属于 v2.2.0，不阻塞 v2.1.0 发布。
