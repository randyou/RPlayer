# RPlayer v0.12.6 — 批量替换缺失文件根目录

## 目标

整库或整专辑移动后，通过旧根目录 -> 新根目录一次修复多条缺失记录。

## 完成项

- 健康检查缺失区域新增「批量替换根目录…」。
- 依次选择旧根目录、新根目录。
- 对每条缺失记录：
  - 大小写不敏感匹配旧根目录前缀；
  - 保留相对子路径拼到新根目录；
  - 新文件存在才更新；
  - 保留曲目 ID、添加时间、收藏与统计；
  - 清除 CUE 虚拟边界字段。
- 完成后刷新缺失列表并提示成功数量。

## 验证

- Release 构建通过。
- `cargo test --release`：39 passed，0 failed。
- 新增 `relink_path_maps_under_new_root` 测试：
  - 正确映射子目录；
  - 不匹配的根目录返回 None。
- 实机打开健康检查窗口，布局无回归。

## 已知限制

- 需要新旧目录结构保持一致。
- 不自动搜索同名文件。
- CUE 虚拟曲目仍不参与单项/批量重新定位。
