# RPlayer v0.11.0 — 动效基础

## 目标

先建立统一的动效 token 和“减少动态效果”开关，为后续页面/列表动画提供基础。

## 完成项

- 新增 `src/ui/motion.rs`：
  - `PRESS = 80ms`
  - `FAST = 120ms`
  - `PAGE = 180ms`
  - `SLOW = 250ms`
  - `duration()` 在 reduced motion 下返回 0。
- 按钮按压缩放改用统一 motion token。
- 页面淡入在 reduced motion 下直接完成。
- `Library` 新增 `reduced_motion` 字段，serde 默认 `false`。
- 设置 → 外观新增「减少动态效果」开关。
- 开关状态持久化并立即应用。

## 验证

- `cargo build --release` 通过。
- `cargo test --release`：29 passed，0 failed。
- 设置页截图检查：
  - 「减少动态效果」与主题、ReplayGain 行左对齐；
  - 开关位于右侧；
  - 无重叠、无溢出。
