# RPlayer v0.12.8 — 批量标签撤销持久化

## 背景

v0.12.5 增加了「撤销上次批量标签」，但撤销记录只保存在内存里，而且批量保存时没有真正写入记录。
结果是命令面板里的撤销经常提示没有可撤销内容，重启后更不可能恢复。

## 目标

- 批量标签保存成功后，记录每首歌修改前的完整 `TagEdit`。
- 记录随 `library.json` 持久化，重启后仍能撤销。
- 撤销成功后清除记录；部分失败时只保留失败项，允许再次撤销。
- 保持原曲目 ID、路径和播放统计不变。

## 实现

- `TagEdit` 增加 `Serialize` / `Deserialize`。
- `Library` 新增 `last_tag_batch: Option<Vec<TagEdit>>`，带 `serde(default)`。
- 批量标签写入成功后设置该字段并保存。
- 撤销从 `library.last_tag_batch` 取记录，失败项回写后再次保存。

## 验收

- 批量修改标签后，重启应用，命令面板仍可撤销。
- 撤销后歌曲标签恢复为修改前内容。
- 部分文件写入失败时，失败项仍保留在撤销记录中。
- `cargo test --release` 全部通过。
