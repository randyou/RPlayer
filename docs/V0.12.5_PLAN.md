# RPlayer v0.12.5 — 批量标签撤销

## 目标

给批量标签写入提供一次会话内撤销，降低误操作风险。

## 完成项

- 批量标签保存成功后，保留本次每个成功曲目的原始 `TagEdit`。
- 命令面板新增 `撤销上次批量标签 · library.undo_tags`。
- 撤销时：
  - 使用原始 Track 重建标签；
  - 重新写入文件；
  - 自动写备份；
  - 替换曲库中的曲目记录；
  - 更新持久化数据。
- 撤销只保留最近一次批量操作，且仅在当前会话有效。

## 验证

- Release 构建通过。
- `cargo test --release`：38 passed，0 failed。
- 标签测试扩展为：
  1. 写入新标签；
  2. 重新读取确认；
  3. 用原始 Track 恢复；
  4. 再读取确认恢复成功。

## 已知限制

- 关闭应用后不能撤销。
- 单曲标签编辑尚未纳入撤销栈。
- 失败曲目不会进入撤销集合。
