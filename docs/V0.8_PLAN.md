# RPlayer v0.8.0

| 字段 | 内容 |
| --- | --- |
| 版本 | v0.8.0 |
| 状态 | 已发布（磨砂玻璃暂缓） |
| 日期 | 2026-11-24 |

## 目标

- 主界面组件边框更浅。
- 歌词面板圆角。
- 歌词面板透明度与歌词文字透明度独立。
- 面板 0% 与悬停状态稳定，不再黑底或残留空面板。
- 评估 wgpu / 原生透明合成路径。

## 已交付

- 六个主题的 `border` / `border_soft` 全部调浅。
- 歌词面板 18px 圆角。
- 面板与文字拆分为独立绘制层：
  - 歌词窗口只绘制文字和控件；
  - 独立 `UpdateLayeredWindow` 面板窗口绘制背景；
  - 面板透明度不再改变歌词文字透明度。
- 面板 0% 时隐藏；悬停显示 16% 面板提示。
- 关闭歌词时同步隐藏面板，避免残留空白面板。
- 版本号统一为 0.8.0。

## 已知限制

Windows 透明合成在当前环境不可用：

- glow 透明窗口无逐像素 alpha；
- wgpu surface 仅支持 `[Opaque, Inherit]`，`PreMultiplied` 会 panic，DX12 surface 创建失败；
- 颜色键、LWA、DWM Acrylic、`UpdateLayeredWindow` 面板均返回成功但最终合成仍为纯色。

因此 v0.8 的面板为分层纯色，不是磨砂玻璃。后续如需磨砂，必须改为 DirectComposition 或完全自绘的 GDI/D3D 歌词窗口。
