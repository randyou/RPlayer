# RPlayer v0.12.7 — CUE 重新定位

## 目标

CUE 专辑的整轨音频文件移动位置后，健康检查里的任意一条虚拟曲目重新定位时，
同一 `.cue` 下的所有曲目一起指向新音频，而不是只修好当前一条。

## 行为

- 普通曲目：保持原有「重新定位」逻辑，更新路径、标题、时长等标签。
- CUE 曲目：
  - 选择新音频后，按 `cue_source` 找到整组虚拟曲目。
  - 所有曲目 `path` 指向新文件。
  - 保留 `track_number`、`cue_start`、`cue_end`。
  - 最后一首的 `cue_end` 改为新音频总时长，并按 `end - start` 重算时长。
  - 保留每首歌的标题、艺术家、收藏和播放统计。
- 健康检查不再隐藏 CUE 曲目的「重新定位…」按钮。

## 验收

- CUE 组内任意一条重新定位后，组内全部曲目路径一致。
- 最后一首结束时间等于新音频总时长。
- 普通曲目重新定位行为不回退。
- `cargo test --release` 全部通过。

## 非目标

- 不自动寻找 CUE 文件本身的新位置。
- 不修改 `.cue` 文本。
- 不处理同时移动 CUE 与音频且需要重建虚拟曲目的场景。
