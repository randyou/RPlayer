# RPlayer v0.12.1 — CUE 解析基础

## 目标

先完成可独立测试的 CUE Sheet 解析，不立即接入扫描/播放，避免半成品数据进入曲库。

## 完成项

- 新增 `src/cue.rs`：
  - `CueSheet { title, performer, file, tracks }`
  - `CueTrack { number, title, performer, start, end }`
- 支持：
  - `FILE "x.flac" WAVE`
  - `TRACK 01 AUDIO`
  - `TITLE`
  - `PERFORMER`（曲目缺失时继承专辑）
  - `INDEX 01 mm:ss:ff`（75 帧/秒）
- 相对 FILE 路径按 CUE 所在目录解析。
- 每个曲目的结束时间由下一轨开始时间填充。
- `load()` 支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM、GBK 回退。

## 验证

- `cargo test --release`：33 passed，0 failed。
- 新增测试：
  1. 专辑/曲目元数据、相对路径、INDEX 时间与结束时间；
  2. 缺少 TRACK/INDEX 时返回错误。

## 暂缓

- 单文件多轨播放与 Seek。
- CUE 编辑/重新扫描。
