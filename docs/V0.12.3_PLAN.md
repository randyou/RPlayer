# RPlayer v0.12.3 — CUE 扫描稳定性

## 目标

让 CUE 虚拟曲目在重复扫描时保持稳定，避免每次扫描重置 ID/添加时间。

## 完成项

- 新增 `model::scan_key(track)`：
  - 普通曲目使用音频路径；
  - CUE 曲目使用 CUE 路径 + 曲目号。
- 扫描器的 known map 改用 `scan_key`。
- CUE 曲目二次扫描：
  - CUE 与音频 mtime 都没变时发送 `Unchanged`；
  - 复用原 ID 与添加时间；
  - 不重复创建数据库记录。
- CUE 文件或音频文件任一变化都会重新解析。

## 验证

- `cargo test --release`：37 passed，0 failed。
- 新增测试：
  1. GBK 编码 CUE 能正确读取标题/曲目；
  2. 二次扫描返回两首 `Unchanged`，不重新生成曲目。

## 已知限制

- 尚未用真实多轨专辑做播放/拖动验收。
- CUE 曲目仍共享整轨封面与歌词。
- CUE 标签编辑暂不写回源文件。
