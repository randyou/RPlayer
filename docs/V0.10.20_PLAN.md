# RPlayer v0.10.20 — 交互审计与验证

## 目标

在不引入大范围视觉改动的前提下，补齐剩余原生按钮的手型光标，并把
“先验证、后提交”的流程固定下来。

## 完成项

- 歌词空状态：从 LRCLIB 搜索、下载当前、编辑歌词。
- 设置页：下载当前歌词。
- 侧栏：管理文件夹。
- 命令面板：命令条目。
- 上述按钮统一 `CursorIcon::PointingHand`。

## 验证

- `cargo build --release` 通过。
- `cargo test --release`：28 passed，0 failed。
- 编辑标签表单截图检查：5 个输入框左右边界一致，label 左对齐。
- 曲库表头与第一行、右侧栏与主区域边界沿用 v0.10.12/v0.10.17 的
  像素修复结果，本次未改动这些布局。

## 暂缓

以下两项需要更长的窗口渲染改造，未纳入本版：

- 歌词颜色键抗锯齿边缘（DirectWrite 文字层评估）。
- 迷你播放器圆角/黑边的 DirectComposition 改造。

## 规则

- UI 改动必须先在实机截图/像素检查通过，再打包。
- 任何版本提交前必须运行 release 测试。
