# RPlayer v2.0.10 — 右键菜单对比度修复

基线：v2.0.9（70 tests，exe 2.0.9.0）
问题：Nocturne 下右键菜单弹层沿用浅色底，菜单行却用当前主题的浅色字，出现“浅字浅底”。

## 1. 原因

- `menu::begin` 只设置行高/宽度，没有显式绘制弹层背景。
- egui 弹层 frame 仍使用旧/回退主题的 `window_fill`，与 `theme::c().text` 不一致。

## 2. 修复

- `src/ui/menu.rs::begin`：用 `theme::c().panel` 显式填充菜单内容区（外扩 6px、8px 圆角）。
- 同步设置 `visuals.window_fill` / `panel_fill`，让子菜单继承同一底色。
- `submenu` 标签显式使用 `theme::c().text`，不再用默认弱化色。

## 3. 验收

- Nocturne：菜单深底浅字，所有可操作行可读；危险项仍为 signal 红。
- Paper：菜单浅底深字，不因本次修复反转。
- 子菜单触发项“评分 / 添加到播放列表”与普通行同色。
- `cargo test --release` 70 passed；exe `2.0.10.0`。

## 4. 已知限制

- 弹层外侧 1px 边框仍由 egui frame 绘制，颜色可能比自绘背景略浅；不影响文字可读性。
