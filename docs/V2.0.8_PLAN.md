# RPlayer v2.0.8 — 桌面歌词菜单与回归流程

基线：v2.0.7（`a86977f`，70 tests，exe 2.0.7.0）
目标：补齐桌面歌词右键菜单的设置入口，并把“改一处、测关联界面”的流程文档化。

## 1. 范围

1. 桌面歌词右键菜单新增“桌面歌词设置…”，点击后主窗口恢复并切到设置第二页。
2. 新增 `docs/qa/v0.2/REGRESSION_LOG.md`：改动→受影响界面→回归方式→结果。
3. 新增 `docs/qa/v0.2/DESIGN_GAPS.md`：缺设计稿的状态先登记，不自行定稿。

## 2. 实现

- `src/overlay.rs`：`OverlayCommand::OpenLyricsSettings`；菜单项使用 `Icon::Settings`。
- `src/app/mod.rs`：处理命令，`settings_open=true`、`settings_tab=1`，恢复并聚焦主窗口。
- 不改桌面歌词 DComp 结构、尺寸、锁定逻辑。

## 3. 验收

- 桌面歌词悬停菜单出现“锁定位置 / 桌面歌词设置… / 关闭桌面歌词”。
- 主窗口设置打开在“桌面歌词”页，左栏高亮正确。
- 1440×900 与 1120×720 下菜单不溢出。
- 桌面歌词默认/悬停/锁定/空歌词四态不回归。
- `cargo test --release` 70 passed；exe `2.0.8.0`。

## 4. 已知限制

- DComp 右键路由仍不稳定；菜单入口在文本窗口可用，遮罩区可能不弹。
- 滑杆仍在齿轮弹层，未搬进右键菜单。
- 顶边缩放、离线/在线失败态、智能歌单规则行仍待设计或后续版本。
