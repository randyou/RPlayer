## v2.0.12 边界与桌面三件小事

### 1. 标题栏顶边（GAP 01）

- 54px 顶栏：顶部 6px、面包屑、空白区全部属于拖动；按钮、搜索、窗口按钮保持各自命中。
- 顶边永不缩放；只有左/右/底边 6px 缩放，顶边不显示 resize 光标。
- 拖动区光标 `Grab`，按下时 `Grabbing`；窗口按钮 34×30。
- 实现建议：`src/app/topbar.rs` 把当前 220px 面包屑拖动层扩为整条顶栏背景层，控件后绘制并吃掉事件；`window_resize_edges` 保持 `top=false`。

验收：顶部 6px 拖动、按钮可点、左右底缩放、双击最大化；1440/1120 双尺寸。

### 2. 桌面歌词菜单与空态（GAP 02 / 06）

- 右键菜单只保留：`锁定位置/解锁位置`、`桌面歌词设置…`、`关闭桌面歌词`；行高 30，无二级菜单。
- 锁定后菜单仍可打开，首项为“解锁位置”；齿轮/关闭隐藏。
- 齿轮弹层 190px：面板不透明度、歌词文字不透明度、`打开桌面歌词设置`；只在 hover 出现。
- 空歌词：标题/歌手 + `暂无歌词` + 行内 `获取歌词` 文字按钮；点击后原位变“正在搜索歌词…”，失败只改行内文案，不弹 toast。
- 实现建议：`src/overlay.rs` 状态机 `LyricsEmptyState { Idle, Searching, NotFound, Offline }`；`platform/dcomp_panel.rs` 命中区覆盖整条菜单/按钮，不再用 `HTTRANSPARENT`。

验收：默认/悬停/锁定/空歌词四态；锁定态可右键解锁；空态可发起获取；860×158 不溢出。

### 3. 迷你播放器紧凑（GAP 07）

- 410×146 固定；标题 14.5/600 单行，最大 250px，超长省略；副行歌手/编号。
- 无封面不占位、不显示“未找到封面”；只保留 28px 播放键和前后 12px 间距。
- 顶部 4 个 24px 动作：置顶/词/展开/关闭。

验收：短标题、超长标题、无封面、无歌手四组；不换行、不撑破 410。

### 4. 设置数据页窄屏（GAP 08）

- 内容宽 ≥360：备份/恢复横排。
- 内容宽 <360：两按钮纵向堆叠、全宽、高 28；说明保留。
- 实现建议：`src/app/settings.rs` 数据页用 `ui.available_width()` 分支，不改设置窗口整体尺寸。

验收：1120×720 与 1440×900；按钮不溢出。

## v2.0.13 规则与批量

### 5. 智能歌单规则行（GAP 05）

- 720 面板；行 field 116 / op 88 / value flex；长值单行省略，悬停显示完整值。
- 空值行：底色 `signal_soft`、行内“缺少值”，保存禁用；只提示一次。
- 最多 5 行可见，超出在规则区滚动；全部条件只在底部出现一次。
- 新增条件后自动聚焦“值”；Tab 顺序：值 → 运算符 → 删除。
- 2px 焦点环，与全局 focus 一致。

验收：长值/空值/多条件三态；保存启用条件；键盘顺序。

### 6. 多选操作条（GAP 09）

- 38px；`已选 N 首` + `不在当前视图` 提示；跨视图选择保留。
- 0 项：条隐藏/危险操作隐藏；3 项：加入歌单/入队/清空；24 项：清空全部/退出。
- 全选当前结果；切换视图不清空选择。

验收：0/3/24 三态、跨视图、全选、清空。

## v2.0.14 失败态

### 7. 离线/在线失败卡（GAP 03 / 04）

统一四类：`404`、`8s 超时`、`429 限流`、`手动离线`。

- 404：`改用文件名匹配` / `手动选择…`。
- 超时：`重试` / `改用缓存`。
- 429：`12 秒后重试`（倒计时禁用）/ `仅用缓存`。
- 手动离线：`本次联网` / `保持离线`。
- 不显示原始错误文本；无缓存时说明“本地曲库与播放不受影响”。
- 实现建议：新增 `src/online/failure.rs` 的 `FailureKind` + `FailureAction`，设置页和在线补全共用；倒计时由 `ctx.input(|i| i.time)` 驱动。

验收：四张卡在 Paper/Nocturne、1120/1440 下可操作；点击后状态复位。

## v2.0.15 首次启动

### 8. 空曲库与文件夹空（GAP 10）

- 空曲库：居中 R 标、`LOCAL LIBRARY · 01`、`把音乐放回桌面。`、一句隐私说明、唯一主按钮 `添加音乐文件夹`；格式支持行 + 三条承诺。
- 已添加文件夹但无音频：`这个文件夹里没有音乐。`、`重新扫描` + `管理文件夹`；不重复“添加音乐文件夹”。
- 支持格式文案：MP3 / FLAC / WAV / OGG / M4A / AAC。

验收：空曲库、文件夹空两态；只有一个主行动；1120/1440。

## 风险

- 顶栏整条拖动层可能吞掉搜索/按钮事件：先做命中测试，再截图验收。
- 歌词 DComp 命中区改动可能让点击穿透到主窗：锁定态只保留菜单，不做 `HTTRANSPARENT`。
- 失败态倒计时需要可测试时钟，避免 UI 测试等待真实 12 秒。
- 规则行 value flex 在 720 面板内需限制最小宽度，防止运算符被挤没。
