# RPlayer v0.12.9 — CUE 分段播放

## 背景

v0.12.2 引入了 CUE 虚拟曲目，但播放路径仍按整轨处理：

- 从整轨 0 秒开始播放，而不是该曲目的 CUE 起点；
- 进度条显示整轨位置，单曲结束时间不生效；
- 播完整个音频文件才切歌，CUE 结束时间被忽略；
- gapless 预加载可能把下一首接到整轨末尾。

## 目标

- CUE 曲目从 `cue_start` 开始播放。
- UI 位置、进度条、歌词时间、会话恢复都使用单曲相对时间。
- 播放到 `cue_end` 自动切到下一首。
- CUE 曲目不参与 gapless 预加载。
- 保持普通曲目行为不变。

## 实现

- 新增 `src/playback.rs`：
  - `start(track, resume)`：相对时间转整轨绝对起点；
  - `absolute(track, relative)` / `relative(track, absolute)`；
  - `reached_end(track, absolute)`。
- 播放启动、seek、当前位置、会话保存统一走这些映射。
- `poll_audio` 在 CUE 结束边界自动 `next_track`。
- 会话 schema 升到 2，旧版 CUE 会话里的整轨位置自动换算成单曲位置。

## 验收

- CUE 第二首从自己的起点开始，进度从 0 开始。
- 到达 CUE 结束时间自动切歌。
- 普通曲目播放、暂停、seek 和会话恢复正常。
- `cargo test --release` 全部通过。
