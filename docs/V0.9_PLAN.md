# RPlayer v0.9.0 · 离线核心

| 字段 | 内容 |
| --- | --- |
| 版本 | v0.9.0 |
| 状态 | 已发布 |
| 主题 | 默认离线、播放稳定、曲库性能 |

## 范围

### P0

1. 默认离线模式
   - 启动、扫描、播放、歌词、封面、歌单、队列均不依赖网络；
   - 自动歌词/封面联网默认关闭；
   - 手动点击仍可按需联网补全。
2. 播放稳定性与错误恢复
   - 失效/损坏文件跳过；
   - 设备切换与回退；
   - 会话恢复可靠。
3. 曲库 SQLite + 增量扫描
   - 旧 JSON 自动迁移并备份；
   - 1 万首二次扫描明显加速；
   - 大曲库搜索/排序不阻塞 UI。
4. 本地歌词/封面
   - 内嵌歌词、同名 `.lrc`、缓存歌词；
   - UTF-8/BOM/GBK；
   - 内嵌封面、目录图片、缓存封面。
5. 歌单/队列/收藏可靠性
   - 顺序持久化；
   - 失效路径提示；
   - 异常退出可恢复。

### 非目标

- 不做 Last.fm、网络电台、播客、CD 抓轨、转码、设备同步、VST、DLNA、可视化。
- 不新增大型 UI。
- 磨砂玻璃继续走独立 DirectComposition 技术线。

## 验收

- 飞行模式下完整走通：启动 → 扫描 → 播放 → 本地歌词/封面 → 歌单 → 队列 → 桌面歌词。
- 离线模式无自动网络请求。
- 1 万首曲库二次扫描显著快于首次。
- 强制结束进程后曲库、歌单、收藏可恢复。
- `cargo test --release` 全部通过。

## 实施顺序

1. 离线模式与联网调用审计（进行中）
2. 播放错误恢复
3. SQLite 曲库迁移
4. 增量扫描
5. 本地歌词/封面编码与优先级
6. 歌单/队列可靠性
7. 测试、文档、打包
