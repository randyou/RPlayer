# RPlayer v2.0.9 — 桌面歌词设置入口

基线：v2.0.8（70 tests，exe 2.0.8.0）
目标：让桌面歌词设置入口不再依赖不稳定的 DComp 右键路由，鼠标左键也能到达。

## 1. 范围

- 桌面歌词齿轮弹层底部新增“打开桌面歌词设置”按钮。
- 该按钮发送 `OverlayCommand::OpenLyricsSettings`，与右键菜单同一路径。
- 不改变滑杆行为、窗口尺寸、锁定逻辑。

## 2. 验收

- 悬停桌面歌词，点击齿轮，弹层内可见“打开桌面歌词设置”。
- 点击后主窗口恢复并切到设置“桌面歌词”页。
- 弹层在 860×158 内不裁切，滑杆仍可拖动。
- `cargo test --release` 70 passed；exe `2.0.9.0`。

## 3. 已知限制

- 右键菜单到设置的 DComp 链路仍待回归。
- 顶边缩放、离线/在线失败态、智能歌单规则行仍待设计或后续版本。
