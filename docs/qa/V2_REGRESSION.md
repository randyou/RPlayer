# RPlayer v2 全量回归清单

目的：**宣布 v2 开发完成前，必须把本清单从头跑一遍**，逐项填「结果 / 证据 / 日期」。任何一项 `失败` 或 `阻塞` 都不得发版。

## 口径

- 环境：Windows 10/11 x64；窗口 1440×900 与 1120×720 各一遍；DPI 100% / 125% / 150% / 200%。
- 数据：真实库 8 首（含 FLAC / WAV / sidecar LRC / 无歌词曲目）+ `testdata\perf10k` 10 001 首。
- 判据：除非特别说明，一律「操作后界面状态正确 + 无残留 + 无控制台报错 + 有截图」。
- 证据命名：`docs/qa/v0.2/v2reg-<组>-<项>.png`；失败项同时记进 `REGRESSION_LOG.md`。
- 工具：见 `tools/qa/README.md`（截图、物理点击、DPI、滚动基准）。

状态取值：`通过` / `失败` / `阻塞`（缺环境或缺设计稿）/ `不适用`。
