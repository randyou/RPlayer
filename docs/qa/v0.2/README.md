## M0 观察

- 原生 Windows 标题栏占 32px；设计稿要求 54px 统一顶栏，需要在 M2 做无边框 spike。
- 曲库为七列表格（评分 / 格式 / 操作独立成列）；1120px 下右侧列被裁切。v2 的 4 列是必要的窄窗修复，不只是审美选择。
- 右栏在 1120px 已自动隐藏；v2 计划把断点明确为 1280px。
- 正在播放已经是独立沉浸页，不是右栏展开；设计规格中补登的 `VIEW.NOW_PLAYING` 与现状一致。
- 当前浅色主题仍是绿色强调 + 系统 sans；v2 的 Paper 暖纸底、森林绿、衬线标题是明显不同的视觉体系。
- 当前页面标题 27px 粗体，设计稿 42px 衬线；M1 先换 token，M2 再改页面头。

## DPI 说明

M0 只记录 100% 缩放。125% / 150% 需要改变系统显示缩放并重启应用，留到 M5 与桌面歌词、迷你播放器一起回归，避免在 M0 影响开发环境。
