# RPlayer 回归测试记录

规则：只要改动的代码可能影响其他界面，就在本表登记“改动 → 受影响界面 → 回归方式 → 结果”。
未执行的回归必须写“待回归”，不得默认通过。

## v2.1.0 托盘菜单 · 实机右键复验

| 改动 | 受影响界面 | 回归方式 | 结果 |
| --- | --- | --- | --- |
| 收起条件从“光标离开弹窗 3 帧”改为“弹窗外左键按下”，轮询间隔 120ms → 40ms | 系统托盘菜单 | 真实右键点通知区 RPlayer 图标（屏幕 1548,957），再移开鼠标 2.2s，再点空白处 | 已回归：菜单打开后悬停移开**保持显示**，点外部立即关闭（`menu hwnd` 1639136 → 0） |
| 定位改用 `cursor_monitor_work_area()`（`MonitorFromPoint` + `GetMonitorInfoW` 工作区） | 系统托盘菜单 | 右下角图标右键 | 已回归：弹窗落在 `1548,659-1816,957`，完整在 1920×1080 工作区内；旧的 `monitor_size` 为 `None` 时回退 1920×1080 会算出偏移 |
| 菜单项动作 | 托盘菜单 → 设置 | 右键图标 → 点“设置” | 已回归：菜单关闭且设置弹窗打开（`_settings3.png`） |

上一版把“光标离开弹窗”当作收起条件，而弹窗是**以托盘图标为锚点**打开的，光标一开始就在弹窗矩形外，于是右键后约 0.4s 自动消失——这是“右键菜单用不了”的直接原因。

## 通用回归清单

任何界面改动至少检查：

- 1440×900 与 1120×720 两种窗口。
- 纸张 / 夜幕两主题。
- 鼠标与键盘焦点路径（Tab / Enter / Esc）。
- 空状态、长文本、最小宽度。
- 受影响窗口的打开/关闭/再次打开。
