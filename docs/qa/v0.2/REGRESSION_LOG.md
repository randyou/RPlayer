## 通用回归清单

任何界面改动至少检查：

- 1440×900 与 1120×720 两种窗口。
- 纸张 / 夜幕两主题。
- 鼠标与键盘焦点路径（Tab / Enter / Esc）。
- 空状态、长文本、最小宽度。
- 受影响窗口的打开/关闭/再次打开。
