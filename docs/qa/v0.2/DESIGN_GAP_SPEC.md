## 1. 自绘标题栏顶边

**结论：顶边不缩放；整条空标题栏是拖动区。**

| 区域 | 行为 |
| --- | --- |
| 顶边 0–6 px（整宽） | 拖动窗口；悬停 `Grab`，不显示垂直缩放光标 |
| 左/右/下 6 px | 原生 `SetWindowPos` 缩放；顶角 6×6 也归拖动，避免误触 |
| 品牌、面包屑、右侧空白 | 拖动；双击空白最大化/还原 |
| 搜索框、歌词/设置/窗口按钮 | 保持自身命中，不触发拖动 |

- 不实现顶边缩放：`src/app/topbar.rs` 的 `let top = false` 保留，等命中测试稳定后再评估。
- 窗口按钮 34×30；关闭按钮 hover 用 signal，其他用 `--surface-raised`。
- 最大化时四边都不缩放，拖动仍可用；双击最大化区域还原。
- 无新增视觉；只更新指针与命中区。

## 2. 桌面歌词右键菜单

**结论：菜单只放命令；连续参数留在齿轮弹层。**

- 菜单宽 188 px，行高 30 px，无二级子菜单，无滑杆。
- 默认三项：`锁定位置` / `桌面歌词设置…` / `关闭桌面歌词`。
- 锁定时第一项变为 `解锁位置`，拖拽禁用，菜单仍可打开。
- 危险项 `关闭桌面歌词` 单独放底部，之前有 1 px 分隔线。
- 齿轮弹层 190 px：`面板不透明度`、`歌词文字不透明度`、`打开桌面歌词设置`。
- 菜单与弹层不重复同一参数；弹层点外部或 `Esc` 关闭。
- 键盘：`Shift+F10` 或菜单键打开；`↑/↓` 移动，`Enter` 执行，`Esc` 关闭。

## 3. 离线模式设置 · 失败态

**结论：先说明本地仍然可用，再给一次明确出口。**

设置页顺序：

1. `默认离线` 开关 + 一句说明“开启后不会自动联网；手动点击封面/歌词仍可在需要时联网补全。”
2. 状态卡 `离线就绪`（LOCAL OK）：本地曲库与队列可用 / 已缓存封面歌词可读 / 当前歌曲没有缓存封面。
3. 失败条 `本次补全没有完成`（OFFLINE）：`当前是离线模式，这首歌也没有本地封面。播放不受影响。`
4. 动作：`本次联网`（primary）、`保持离线`（ghost）。

| 状态 | 文案 | 动作 |
| --- | --- | --- |
| 离线且缓存完整 | 离线就绪 | 无 |
| 离线且缺封面 | 当前离线，本地没有可用封面 | 本次联网 / 保持离线 |
| 手动补全超时 | 请求超时，本地内容没有变化 | 重试 / 保持离线 |
| 源不可达 | 暂时连不上封面源 | 稍后重试 / 保持离线 |

禁止：原始错误码、红色整页、自动切换在线、清空已有缓存。

## 4. 在线内容设置 · 失败态

**结论：失败只落在“最近一次请求”行内，不改变全局开关。**

| 情况 | 标题 | 说明 | 主动作 | 次动作 |
| --- | --- | --- | --- | --- |
| 404 | 没有找到匹配的封面/歌词 | 源里没有可用条目，当前占位保留 | 改用文件名匹配 / 手动选择… | 关闭 |
| 超时 8 s | 请求超时 | 源没有在 8 秒内响应；本地内容没有变化 | 重试 | 改用缓存 |
| 429 | 请求过于频繁 | 自动请求已暂停，12 秒后可以再试 | 12 秒后重试（disabled） | 仅用缓存 |
| 离线 | 当前离线 | 自动请求已暂停；手动操作允许单次联网 | 本次联网 | 保持离线 |

- 失败行内显示，不弹 toast，不遮挡列表。
- 404 的“改用文件名匹配”只用本地文件名，不发起第二次网络请求。
- 超时固定 8 s；按钮倒计时结束自动恢复，不刷新页面。
- 429 倒计时期间按钮 disabled，显示剩余秒数。

## 5. 智能歌单规则行

**结论：一条规则一行，值列弹性，错误就地显示。**

- 行高 34 px；列宽：序号 22 / 字段 116 / 运算符 82 / 值 `1fr`（min 160）/ 删除 24。
- 值超长：单行省略，悬停 `title` 显示完整值；不换行、不撑高面板。
- 空值：行内红边 + 底部 `第 3 条规则缺少值`；`保存智能歌单` 禁用。
- 多条件：720 px 面板最多完整显示 5 行，之后列表内滚动；底部“添加条件”始终可见。
- 新行自动聚焦值输入；Tab 顺序：字段 → 运算符 → 值 → 删除。
- 不做拖拽排序；删除用 24×24 命中，hover 才显 signal。

## 6. 桌面歌词 · 空歌词

**结论：给一个行内动作，不弹窗、不跳设置。**

空态内容：

```
陈屿 · 雨后站台
暂无歌词
将同名 .lrc 放在歌曲目录，或 获取歌词
```

| 状态 | 显示 |
| --- | --- |
| 有空、可联网 | `获取歌词` 文本按钮 |
| 搜索中 | `正在搜索歌词…` + 8 px 转圈，按钮不可重复点 |
| 未找到 | `没有找到匹配歌词 · 重试` |
| 网络失败 | `网络不可用 · 重试` |
| 锁定 / 无歌曲 | 隐藏按钮与提示 |

- 按钮不填充底色，accent 文字 + 下划线；命中高度 32 px，宽度 ≥ 64 px。
- 失败不弹 toast，不遮歌曲信息；重试留在原位。
- 自动下载歌词仍归“在线内容”设置，不在空态里重复开关。

## 7. 迷你播放器 · 紧凑长标题 + 无封面

**结论：紧凑模式不靠封面撑布局；标题永不换行。**

- 窗口固定 410×146，四角 16，内边距 14 / 12。
- 紧凑标题：14.5 / 600，单行，最大 250 px；超出省略，悬停给完整标题。
- 副行 9 / 400：`艺术家 · 编号`；艺术家为空写 `未知艺术家`。
- 紧凑无封面：不放占位图，左内边距 12；封面不参与文字宽度计算。
- 经典模式保留 92×92 占位，用音符底，不显示“未找到封面”文案。
- 顶部 4 个 24×24 动作：置顶 / 歌词 / 展开 / 关闭，间距 8；不挤压标题。
- 底部播放 28 圆，前后 12 图标；喜欢在右下角，与主播放区分离。

## 8. 设置弹窗 1120×720 · 数据页

**结论：1120 下双按钮不换行；只有内容宽 < 360 才堆叠。**

- 内容宽 564（1120 窗口减去 236 导航与内边距）。
- `备份数据…` 与 `恢复数据…` 各 128×34，间距 8；总宽 264，余量充足。
- 恢复确认仍为单独确认框，不在按钮上做二次确认。
- 内容宽 < 360：两按钮 100% 宽、上下间距 8，顺序不变（备份在上、恢复在下）。
- 底部 `完成` 始终固定在窗口底部，不随内容滚动。
- 禁止：缩小字号、图标按钮替代文字、把两个动作塞进下拉。

## 9. 多选操作条

**结论：操作条始终说明“选了多少、在哪、能做什么”。**

| 状态 | 内容 | 动作 |
| --- | --- | --- |
| 0 选中 | `已选 0 首` + 提示“Ctrl 点击 · Shift 范围选择” | 全选当前结果 / 退出 |
| 3 选中 | `已选 3 首` + `1 首不在当前视图` | 加入歌单 / 加入队列 / 清空 |
| 24 选中（跨视图） | `已选 24 首` + `6 首不在当前视图` | 清空全部 / 退出 |

- 条高 38 px，固定在列表底部、播放条上方；不遮最后一行。
- “全选”只选当前筛选结果，不跨页、不跨视图。
- 切换筛选或视图不清空选择；显示“不在当前视图”的数量。
- 0 选中不显示批量动作；`Esc` 退出多选，`Ctrl+A` 全选当前结果。

## 10. 首次启动空曲库

**结论：一个主按钮，先给结果，再解释能力。**

```
把音乐放回桌面。

RPlayer 只读取你的文件夹，不上传、不联网也能播放。

[添加音乐文件夹]

支持 MP3 / FLAC / WAV / OGG / M4A / AAC · 也可以把文件夹拖进窗口
不要求登录 · 不复制文件 · 随时移除
```

- 只有一个 primary，没有“导入”“登录”“在线音乐”竞争入口。
- 整块空态可拖入文件夹；拖入时整块描边变 accent。
- 已有文件夹但没有音频：

```
这个文件夹里没有音乐。

已添加 2 个文件夹。检查扩展名，或换一个文件夹。

[重新扫描]  [管理文件夹]
支持 MP3 / FLAC / WAV / OGG / M4A / AAC
```

- 不重复“添加音乐文件夹”作为主按钮；用户已经有文件夹，任务是修复扫描。
- 空态不显示统计、推荐、最近播放等零数据模块。

## 动效与可访问性

- 菜单/弹层：140 ms `ease-out`；模态：280 ms `ease-out`；无场景级 520 ms 动画。
- 空态按钮 hover 只改文字色/下划线，不做位移；按下 90 ms。
- 减少动态效果时全部 0 ms；转圈保留但降为静态“搜索中”。
- 所有新按钮有 AccessKit 名称；错误条 `role=alert`；多选条 `aria-live=polite`。
