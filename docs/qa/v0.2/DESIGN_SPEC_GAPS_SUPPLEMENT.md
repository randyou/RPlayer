# 设计缺口补充 · D1–D15

基线：RPlayer v2.0.17。补稿日期：2026-11-25。
本文件为 `DESIGN_SPEC_GAPS.md` 的配套说明，逐项给出尺寸、状态、文案、交互与动效。像素稿见同目录 `spec2-*.png`，合集见 `RPlayer-v2-设计缺口补充-D1-D15.pdf`（6 页）。

所有尺寸为 100% 逻辑像素；颜色取 `tokens.css`。动效 token：press 90ms / hover 140ms / base 280ms / scene 520ms；曲线 out `cubic-bezier(.22,1,.36,1)`；`prefers-reduced-motion` 或应用内“减少动态效果”开启时全部为 0ms，只保留透明度变化。

## 1. 系统托盘 D1–D4

稿：`spec2-tray.png`，PDF 第 1 页。

- **尺寸** 280×366；圆角 8；纸色 `#FAF6ED` / Nocturne `#151914`；1px 外框；无系统菜单阴影之外的装饰。
- **结构** 58px 抬头（36px 封面、曲名、艺人、`2:59 / 3:48`），其下 2px 只读进度；菜单行 30px；三组：传输 / 收藏·桌面歌词·迷你 / 设置 / 退出，组间一条分隔线，不写组标题。
- **状态** 无曲目：抬头显示“未在播放”，传输行 35% 透明度且禁用；播放中：播放行显示“暂停”；勾选项：收藏、桌面歌词、迷你播放器右侧 12px 对勾。退出永远最后一行，signal 红 `#B64B31`。
- **D2 托盘图标** 16/24/32 使用新标识，不随播放状态换脸；状态只出现在提示与菜单。32px 以下不加描边、不加投影。
- **D2 悬停提示** `RPlayer · 正在播放` + 第二行 `一千年以后 — 林俊杰`；暂停时 `RPlayer · 已暂停`；无曲目 `RPlayer · 未在播放`。
- **D3 点击** 单击 = 显示并聚焦主窗口；双击 = 播放/暂停；右键 = 菜单；中键 = 无动作。不做单击隐藏，避免与双击冲突。
- **D4 系统通知** 不做 OS 级 toast。切歌静默；下载完成 / 失败进入应用内 toast 与“在线内容”状态区。理由：托盘已是常驻入口，系统通知会重复且不可撤回。
- **动效** 菜单打开 140ms opacity + 2px 上移；分组不逐个 stagger。
- **实现提示** 当前 `TrackPopupMenu` 为原生菜单；稿是品牌化目标态。若保留原生菜单，只能改文案与分组，不能改圆角/行高；需在版本说明中标注差异。

## 2. 迷你播放器 D15

稿：`spec2-mini.png`，PDF 第 2 页。

- **画布** 固定 410×146，圆角 16；不随标题长度变化。外层 5px 左侧 accent 只用于“经典”样式。
- **经典** 92×92 封面；无封面时保留 92×92 音符占位，不显示“未找到封面”文案；标题 14.5/600，单行，最大 250px，超出省略 + tooltip。
- **紧凑** 不显示封面，也不留封面空位；标题左移 14px；标题单行 250px 上限；其余与经典共用播放/上一首/下一首/收藏。
- **顶部动作** 4×24：置顶、桌面歌词、展开、关闭；间距 8；hover 才显示；不挤压标题宽度。
- **播放** 28px 圆形主按钮；上一首/下一首 20px；收藏固定右下，不参与标题排版。
- **8 态** 经典/紧凑 × 浅/深 × 有/无封面；另加 hover 与拖动。拖动时 1px 虚线 accent + 阴影，不显示“松开”遮挡按钮。
- **文案兜底** 艺人空 → `未知艺术家`；标题空 → `未命名曲目`；均不换行。
- **动效** 窗口进入 280ms opacity + 4px 上移；hover 140ms；播放按钮 press 90ms scale .975。

## 3. 曲库健康检查 / 重复歌曲 D5–D6

稿：`spec2-library-tools.png`，PDF 第 3 页。

- **健康检查** 720×340。抬头 66；三张数字卡（缺失文件 / 空标签 / 重复候选），数字 30px serif；问题行 44px，左图标 + 文案 + 右侧单一动作（定位 / 去编辑 / 查看）；底部 `重新检查`。空态：绿色对勾 + `没有发现明显问题` + `已扫描 8 首，缺失文件 0 · 空标签 0 · 重复候选 0。`
- **队列状态** 扫描中 62%：`1,240 / 2,018 首 · 可继续播放` + 进度条；错误：`D:\Archive 无法读取` + `跳过该目录，其余曲库继续扫描` + 重试/忽略。
- **重复歌曲** 720×340。组头 `龙卷风 — 周杰伦` + `1 组 / 2 个文件`；两行文件（FLAC 保留 / MP3 忽略），高亮行左侧 2px accent；行内 `仅保留此首` / `定位`；底部危险动作 `删除 1 个重复项` 独立右侧，`忽略本组`/`取消` 退为描边。
- **规则** 健康检查不提供“一键全修”；重复清理不自动删除，删除只移出曲库，文件保留。
- **动效** 数字与列表 280ms 淡入；删除确认 280ms；进度条 520ms 线性（仅进度，不做循环动画）。

## 4. 编辑歌词 / 智能歌单 / 均衡器 D7–D9

稿：`spec2-edit-tools.png`，PDF 第 4 页。

- **歌词编辑器** 820×430。行高 36；时间列 58/82；当前行 accent-soft + 2px 左条；播放/删除 22×22；底部固定 `取消 / 保存歌词`；脏状态 `未保存` 标记。时间格式 `mm:ss.xx`，非法行只标红该行，不弹窗。
- **智能歌单** 620×430。条件行三段：字段 116 / 操作 88 / 值 flex；行高 34；空值行红框 + 底部仅一条 `第 3 条规则缺少值`，保存禁用；实时预览 `0 首匹配` 放底部上方；超过 5 行滚动，不压缩行高。
- **均衡器** 820×250，Nocturne 面板。10 段竖推子 62px 间距；预设单行横向滚动，不折行；前级 +0.0 dB；重置；修改即时生效，不写音频文件。
- **动效** 当前歌词行 140ms；推子拖动 0ms 跟手；预设切换 140ms；保存成功 toast 280ms。

## 5. 快捷键 / 关于 / 拖入 / 错误 D10–D12

稿：`spec2-system-ui.png`，PDF 第 5 页。

- **快捷键** 820×460。21 条，两栏 10/11；每行 26px；按键 88px 列；分组 `全局 / 播放 / 列表与选择 / 焦点`；底部说明可重绑、冲突以后设置者为准。焦点内 Space 激活控件，不触发全局播放。
- **关于** 380×280。44px 标识；`RPlayer` / `v2.0.17 · 本地优先`；数据目录、开源许可、构建；不做“检查更新”主按钮。
- **拖入** 380×220。目标行 1px 虚线 accent + accent-soft 底；右侧 `+3` 徽标 + `松开以添加`；底部提示“拖到任意歌单行即可添加 · 不改变当前播放队列”。拖拽中不改变行高，不显示全屏遮罩。
- **错误详情 D12** 应用内展开，不另开日志窗口。标题 `无法读取「…」`；一行原因；元数据 路径 / 错误码 / 时间；`诊断` 行（os error 32 · 文件被占用 · 已重试 2 次）；动作 `在文件夹中显示` `复制诊断信息` `重试`。展开 280ms，只推下方内容，不遮挡播放条。
- **原则** 破坏性动作独立右侧或底部；同一错误只出现一次，不重复 toast。

## 6. 200% DPI / 极窄布局 D13

稿：`spec2-responsive.png`，PDF 第 6 页。

- **断点** ≥1280：236 侧栏 + 300 右栏；1120–1279：隐藏右栏；840–1119：侧栏收为 72 图标，曲库表隐藏专辑列，播放条 76；<840：侧栏抽屉化，播放条两行 96，对话框 `min(92vw, 720px)`。
- **1024×720 稿** 侧栏 72、无右栏、表列 `# / 曲目+艺人 / 时长`；页头 32；播放条 76。
- **720×720（200% DPI 的 1440 物理）** 抽屉盖住内容 150px；不缩字号；播放条两行，进度独占一行。
- **规则** 不缩放字体；不改常驻信息密度；先减少列、再隐藏右栏、最后抽屉化。最小逻辑宽度 720，不再承诺 1120 以下完整布局。
- **动效** 抽屉 280ms；断点切换不播动画，直接重排，避免 resize 抖动。

## 7. 桌面歌词 color-key 白边 D14

稿：`spec2-responsive.png` 右下，PDF 第 6 页。

- **决定** 接受 1px 白边，不新增分层窗口/整窗透明渲染路径。理由：当前局限只在浅色桌面可见，换渲染路径会引入性能与点击穿透风险。
- **缓解** 浅色桌面文字加 `0 0 1px rgba(0,0,0,.35)`；深色桌面加 `0 0 1px rgba(255,255,255,.22)`。仅阴影，不描边、不加底色块。
- **验收** 在 50% 灰、纸色、浅绿照片三种壁纸上，当前行对比度 ≥ 4.5:1；白边不得宽于 1px。
- **说明** 该限制写入设置·桌面歌词的说明文字，不在 UI 中暴露技术术语。

## 8. 新标识

稿：`design/rplayer-v2/brand/brand-sheet.png`，PDF `RPlayer-v2-品牌标识.pdf`，源 `rplayer-mark.svg` / `rplayer-lockup*.svg`。

- **概念** Sleeve R：森林色唱片套包住纸色 R；两个字“套 + R”。远看是 R，近看是封套。
- **色** 仅 `#2E5B44` + `#F4EFE5`；Nocturne 用 reversed 组合；signal 红只用于状态，不进标识。
- **最小尺寸** 标识 16px；横向组合字标 ≥ 12px；堆叠组合 ≥ 132px。
- **留白** `x = 1/4 标识宽`；四边不小于 x；标记内不放文字、线框或第二个标识。
- **禁止** 不加投影、不用渐变、16–24px 不描边、深底必须反白。
- **资产** favicon 32、apple-touch 180、OG 1200×630 已生成；Cascadia Mono 未安装处回退 Consolas。
