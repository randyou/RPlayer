## 4. 补稿时需要的产出物

每个面至少给：浅色 + 深色两张 1× 稿、关键态（默认/悬停/选中/禁用/空/错误）、与相邻面的间距对齐说明。放在 `docs/qa/v0.2/`，命名 `spec-<面>-<态>.png`，并在本表对应行的「现状」列回填稿文件名。

验收：补稿后，该面在 `SURFACE_MATRIX.md` 的证据列换成"稿 + 实现截图"两张，回归时按稿逐项比对。
