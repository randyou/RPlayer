## 1. 目标与边界

### 1.1 这次要解决什么

当前 0.13.5 的功能完整，但界面的注意力被平均分给了七列表格、六套主题、常驻右栏和原生标题栏。v0.2 只做三件事：

1. **建立“聆听室”视觉身份**：暖纸、墨色、森林绿、衬线标题，Paper / Nocturne 两套主题形成记忆点。
2. **重排主界面注意力**：曲库从七列降到四列；当前播放行、封面、歌词和下一首成为第一视觉层级。
3. **统一交互与动效**：36px 控件、8/10px 圆角、2px 焦点环、140/280/520ms 动效 token；键盘与鼠标走同一套状态。

### 1.2 成功标准

- 59 个设计表面全部有实现或明确的原生替代，12 条 flow 可完整走通。
- 1440×900 与 1120×720 两个尺寸下，主界面无横向滚动、无关键内容裁切。
- 键盘可完成：切页、选歌、播放、搜索、打开命令面板、队列、设置、关闭弹层。
- 现有 59 个测试全部通过；新增 ≥11 个测试，最终 ≥70。
- 启动时间、滚动帧率、内存不出现可感知回退；安装包不因字体嵌入显著膨胀。
- 不破坏 0.13.5 的曲库、歌词、备份、标签、CUE、播放统计与会话数据。

### 1.3 明确不做

- 不重写音频管线、WASAPI 输出设备、扫描器、数据库 schema。
- 不新增设置分组；设置仍为 6 组：外观 / 桌面歌词 / 迷你播放器 / 离线模式 / 在线内容 / 数据。
- 不引入网络字体、远程封面、在线歌词作为 UI 运行依赖。
- 不做托盘 owner-draw；首版保留原生 Win32 菜单语义，只增加分组、勾选与当前曲头。
- 不在这一版实现列表拖拽排序、跨列表拖放等设计稿标注为“实现阶段再加”的能力。
- 不为 `src/stats.rs`、`src/app/session.rs`、`src/platform/dcomp_panel.rs` 虚构界面。

## 2. 开工前必须冻结的决策

### 2.1 版本号与升级路径（阻塞）

用户指定 **v0.2**，但当前版本是 **0.13.5**。如果二进制版本写成 `0.2.0`，语义上小于 `0.13.5`，现有用户、未来的自动更新与包管理器不会把它识别为升级。

必须在写第一行 UI 代码前选一种：

| 方案 | 版本字段 | 适用情况 | 代价 |
| --- | --- | --- | --- |
| A（推荐） | `2.0.0` | 把“v0.2”理解为第二代设计，而不是 0.2 语义版本 | 与用户口头版本号不同，需要文档解释 |
| B | `0.14.0` | 保留 0.x 单调递增，对外称“v0.2 设计版” | 对外版本号与内部不一致 |
| C | `0.2.0` | 只做全新安装 / 手工分发 | 旧版无法自动升级，商店版本倒退 |

**建议 A。** 本计划其余部分暂用“v0.2”指代产品线，不预设 Cargo 版本。

### 2.2 自定义标题栏

设计稿要求 54px 顶栏合并面包屑、搜索、主题、设置和窗口控制。当前使用 Windows 原生标题栏。

- **建议**：先做 2 人日的无边框窗口 spike，验证拖动、双击最大化、边缘缩放、多显示器 DPI、DWM 阴影。
- **失败回退**：保留原生标题栏，顶栏放到其下方，仍保留面包屑与搜索；视觉损失可接受。
- 不在 spike 通过前改其他布局，避免三套坐标系统同时存在。

### 2.3 主题收敛

设计只暴露 **Paper / Nocturne** 两套；当前有 Paper / Sand / Mist / Forest / Midnight / Charcoal 六套。

- 保留六套 palette 代码，不删除旧值。
- 设置只渲染两张主题卡；旧用户值映射：`paper/sand/mist → Paper`，`forest/midnight/charcoal → Nocturne`。
- `Ctrl+T` 只做 Paper ↔ Nocturne。
- 默认主题改为 Paper；这是有意的产品变更，发布说明必须写明。

### 2.4 曲库主表

- 主表从 7 列降为 4 列：`# / 曲目 / 专辑 / 时长`。
- 评分、格式、收藏不删除数据，只移出主列：格式进曲名后的 8px 徽标，收藏在 hover / 当前行出现，评分留在右键菜单。
- 行高 56px，缩略封面 38px，曲名 13px，艺术家 9.5px。
- 排序、筛选、搜索、多选、批量条能力保持不变。

### 2.5 右栏断点

- 右栏 300px，仅在窗口宽度 ≥1280px 时显示。
- 1280px 以下自动收起；正在播放信息由播放条与“正在播放”页承接。
- 断点必须用真实窗口拖拽验证，不能用 `screen_rect` 猜。

### 2.6 菜单与托盘

- 6 个右键菜单自绘，统一 30px 行高、1px 分隔线、危险动作置底。
- 曲目菜单按 5 组重排，子菜单延迟 120ms。
- 托盘保留原生菜单，首版只加分区分隔、勾选状态与当前曲头；不做自绘。

### 2.7 迷你播放器密度

- 410×146，经典 / 紧凑两种密度都进入首版。
- 当前代码已有两种密度与尺寸，这次主要是重绘与统一状态，不是重写窗口。

### 2.8 补一个设计规格缺口

`design/rplayer-v2/shots/03-now.png` 与 `09-dark-now.png` 是完整的“正在播放”页面，但 `inventory.json` 没有 `VIEW.NOW_PLAYING` 条目，只有 `CHROME.NOW_RAIL`。

开工前必须做：

- 在 `inventory.json` 增加 `VIEW.NOW_PLAYING`，或在 `CHROME.NOW_RAIL` 中明确它是展开态；
- 同步 `interactions.json` 的进入 / 返回 / 沉浸动作；
- 更新计数与 README，避免实现阶段把它当成“右栏放大”。

| 字体 | 微软雅黑 / 系统 sans | 标题 Noto Serif SC，正文 Noto Sans，元数据 mono | 需字体回退策略 |
| 页面标题 | 27px 粗体 sans | 42px 衬线，带 eyebrow 与 meta | 所有主页面 |

| 设置 | 470px 宽单列滚动 | 720×640 双栏，6 组，即时生效 | 组件与信息架构重排 |
| 右键菜单 | egui 默认 `context_menu` | 6 个自绘菜单，30px 行高、分组、危险色 | 键盘/边缘翻转成本 |

## 5. 工程架构

### 5.1 新增 / 调整模块

```text
src/ui/
  tokens.rs        // 新：颜色、间距、字号、圆角、阴影、断点数值
  motion.rs        // 扩展：90/140/280/520ms、easing、reduced motion
  components.rs    // 新：page header、eyebrow、keycap、chip、empty state、equalizer
  menus.rs         // 新：自绘菜单、子菜单延迟、键盘导航、边缘翻转
  focus.rs         // 保留：2px 焦点环

src/app/
  shell.rs         // 新：标题栏、顶栏、窗口控制、面包屑、搜索入口
  sidebar.rs       // 重写视觉与分组，保留导航与拖放语义
  player_bar.rs    // 重排三栏，92px 高
  now_rail.rs      // 300px，三段式
  library_view.rs  // 4 列表格 + 页面头 + 批量条
  now_playing.rs   // 沉浸页重绘
  settings.rs      // 720×640 双栏
  dialogs.rs       // 11 个对话框统一骨架
```

### 5.2 不变量

- 所有颜色继续通过 `theme::c()` 取得，组件内不写十六进制。
- 保留现有中文入口名：本地曲库、我的收藏、最近播放、音乐目录、播放队列、正在播放、设置。
- 每个可交互控件保留 AccessKit label、tooltip 与键盘路径。
- 数据层不动：`model.rs`、`scanner.rs`、`storage.rs`、`backup.rs`、`playback.rs` 不因 UI 改版修改 schema。
- 主题字段仍使用现有字符串持久化；新增映射函数，不做数据库迁移。
- 桌面歌词 / 迷你播放器继续复用现有 viewport 与 `OverlayCommand`，只替换绘制层。

### 5.3 字体策略

- 标题族：`Noto Serif SC` → `Source Han Serif SC` → `Songti SC` → `STSong` → `SimSun`。
- 正文族：`Noto Sans SC` → `Microsoft YaHei UI` → `Microsoft YaHei` → `PingFang SC`。
- 元数据族：`Cascadia Mono` → `Consolas` → 等宽回退。
- 不下载网络字体；优先读取系统字体。若目标机器无衬线字体，回退到 `SimSun`，不阻断启动。
- 本机已确认存在 `C:\Windows\Fonts\NotoSerifSC-VF.ttf`；仍需在无 Noto 的 Windows 环境做一次回退截图。
- 只有视觉验收确认系统回退不可接受时，才评估嵌入子集字体；嵌入会使安装包增加约 10–25MB，默认不做。

## 6. 里程碑

> 估算按 1 名熟悉 egui 的工程师计算；M3/M4 可在 M2 冻结后并行拆分。

### M0 · 计划冻结与规格修补（0.5 人日）

- 冻结 §2 的 8 个决策。
- 补 `VIEW.NOW_PLAYING` 到 inventory，校验 motion/interaction 引用。
- 保存 0.13.5 基线截图：1440×900、1120×720、100/125/150% DPI。
- 建立 `docs/qa/v0.2/` 视觉回归目录与检查表。
- **退出条件**：设计规格无坏引用，版本号方案确定。

### M1 · Design tokens 与字体（2 人日）

- 新增 Paper / Nocturne palette；旧 palette 保留，设置只展示两套。
- 注册衬线 / sans / mono 三族；建立 10/11/12.5/13.5/16/20/28/44/64 字号阶梯。
- 建立 4/8/12/16/20/24/32/40/56 间距、6/10/14/20 圆角、阴影 token。
- 重写 `motion.rs`：90/140/280/520ms、ease-out / in-out、reduced motion 全归零。
- 建立基础组件：按钮、图标按钮、chip、keycap、输入框、开关、滑杆、焦点环。
- **退出条件**：现有界面在不改布局的情况下完成“换肤”；59 个旧测试通过；新增主题映射与 token 测试。

### M2 · 应用框架与曲库（4 人日）

- 无边框标题栏 spike：拖动、双击最大化、边缘缩放、DPI、DWM 阴影；失败则回退原生标题栏。
- 侧栏 236px：品牌、资料库分组、歌单分组、队列、存储状态、版本号。
- 顶栏 54px：面包屑、居中搜索、离线点、主题、歌词、均衡器、设置、窗口控制。
- 播放条 92px：48px 封面、曲名/艺术家、收藏、五键传输、进度、模式、歌词、队列、音量、沉浸。
- 右栏 300px，≥1280px 显示；三段式：封面 / 当前信息 / UP NEXT。
- 曲库 4 列表格：页面头、tabs、排序、行状态、hover 操作、批量条、空态/搜索空态。
- 键盘：行焦点、Enter 播放、Space 选择、Home/End/PageUp/PageDown、焦点环。
- **退出条件**：M2 的 14 个表面通过视觉检查；播放 / 搜索 / 批量 / 队列入口可用；1280px 断点验证。

### M3 · 浏览与正在播放（4 人日）

- 专辑：5 列封面墙 + 导入卡；1200/1000px 降为 4/3 列。
- 专辑详情、艺术家、艺术家详情、歌单、智能歌单：统一页面头、hero、返回、空态。
- 正在播放：430px 封面、60px 标题、32px 歌词、当前行短线、封面取色环境光、返回 / 沉浸。
- 播放条左侧在沉浸页切换为“沉浸歌词”入口。
- 补 `VIEW.NOW_PLAYING` 规格与实现映射。
- **退出条件**：M3 的 7 个表面通过；专辑/艺术家/歌单的无图、少图、长标题三组数据都不破版。

### M4 · 命令、队列、设置、对话框与工具（4 人日）

- 命令面板：分组（跳转 / 曲目 / 操作）、固定每组 3 条、`↑↓`、Enter、Esc、底部快捷键提示。
- 播放队列：右侧抽屉，当前曲卡 + 列表 + 来源/模式，Esc 关闭，焦点回到触发点。
- 设置：720×640 双栏，6 组；主题两张卡；即时生效；外观页加预览区。
- 11 个对话框：统一 180px 基准、标题/说明/正文层级、单主操作、危险动作信号红。
- 4 个工具窗口：EQ、智能歌单、健康检查、歌词编辑器共用 8px 圆角、36px 行高、滑杆/开关。
- 6 个右键菜单自绘：30px 行高、分组、危险动作置底、子菜单 120ms、键盘导航、屏幕边缘翻转。
- **退出条件**：M4 的 25 个表面通过；12 条 flow 中除桌面外设外全部可走通。

### M5 · 桌面外设（2 人日）

- 桌面歌词：默认 / 悬停 / 锁定 / 无歌词四态；860×158；控件仅 hover/focus 出现；双击锁定/解锁。
- 迷你播放器：经典 / 紧凑两密度，410×146；共用进度、播放态、收藏、置顶、吸附。
- 托盘：原生菜单，增加分组、勾选、当前曲头；退出确认。
- 100% / 125% / 150% DPI 与多显示器检查。

## 7. 动效实现计划

### 7.1 Token

| Token | 时长 | 用途 |
| --- | --- | --- |
| instant | 0ms | 关闭 / 选中态的即时反馈 |
| press | 90ms | 按钮按下、开关 |
| fast | 140ms | hover、菜单、toast、焦点环 |
| base | 280ms | 页面进入、弹窗、主题切换、列表入场 |
| scene | 520ms | 封面 crossfade、正在播放场景进入 |

曲线：`ease-out ≈ cubic-bezier(0.22,1,0.36,1)`；主题切换用 `ease-in-out`；关闭用 `ease-in`。

### 7.2 八个原语

1. **Press**：按钮背景 + 最多 1px 收缩；不移动命中区域。
2. **Hover**：背景 / 边框颜色，140ms；不位移。
3. **EnterPage**：透明度 + 6px 上移，280ms；reduced 只保留透明度。
4. **EnterModal**：遮罩透明度 + 面板 0.98→1 缩放，280ms；关闭 140ms。
5. **Drawer**：右栏 translateX，280ms 开 / 140ms 关。
6. **Toast**：透明度 + 6px 上移，140ms；退出只淡出。
7. **Crossfade**：封面 / 主题色，520ms；不做循环。
8. **Focus**：2px 外环，90ms 颜色过渡；不能被子元素底色吞掉。

### 7.3 egui 约束

- egui 没有 CSS transform。位移通过预先计算 rect 偏移实现；缩放通过 `Painter` 画缩放后的内容，或只改颜色/透明度。
- 禁止动画 `width/height` 触发重排；drawer 与进度条只画，不参与布局。
- 48 条模式不逐一写 48 个函数；映射到上述 8 个原语 + 参数。
- 唯一允许的循环动画是当前播放电平条；reduced motion 下冻结为静态四格。
- 动效状态用 `Id` 稳定 key，列表重排不能重置动画。

## 8. 测试与验收

### 8.1 单元测试（目标 ≥70）

在现有 59 个基础上新增：

- 旧主题 → Paper/Nocturne 映射；未知值回退 Paper。
- palette 对比度（正文、muted、faint、on-accent、sidebar 文字）在 Paper / Nocturne 均达标。
- motion token 数值；reduced motion 下时长全为 0；easing 端点。
- 布局断点：侧栏、右栏、表格列、专辑 5/4/3 列。
- 4 列表格的排序/筛选不改数据顺序。
- 命令面板分组、每组 3 条、空结果。
- 菜单键盘：↑↓、Enter、Esc、子菜单 120ms、危险动作置底。
- 焦点恢复：切页、关闭抽屉、关闭对话框回到触发点。
- 标题栏命中区：拖动区/按钮区/缩放边缘（纯函数）。

### 8.2 视觉回归

- 每个主界面在 1440×900 与 1120×720 各一张截图，命名 `docs/qa/v0.2/<surface>-<size>-<theme>.png`。
- 与 `design/rplayer-v2/shots/` 对照，记录差异与“有意偏差”。
- 系统图版按 1600×1000 检查对话框 / 菜单 / 工具 / 设置。
- 100% / 125% / 150% DPI 各跑一遍主界面、桌面歌词、迷你播放器。

### 8.3 可访问性

- 键盘走完 12 条 flow：不允许只能用鼠标的入口。
- 焦点环在所有主题、所有行状态可见；不能被选中底色覆盖。
- AccessKit：同名按钮必须有上下文标签；行标签唯一；对话框标题即 label。
- 颜色不是唯一状态：当前播放同时有竖线、底色、电平条；收藏有心形填充 + label。
- 图标按钮 ≥24px，主要操作 36px；文本对比度达标。

### 8.4 性能与回归

- 10k/30k 曲目合成库：滚动、搜索、切页无长时间卡顿。
- 启动、切主题、打开设置、打开命令面板的耗时记录在 `docs/qa/v0.2/perf.md`。
- 音频、扫描、CUE、备份、标签、会话、统计逐项 smoke test。
- 安装包体积只允许因代码增加小幅增长；不嵌入 CJK 全量字体。

## 9. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
