# RPlayer v0.12.2 — CUE 曲库接入

## 目标

把 CUE 解析接入扫描与播放，同时不破坏现有普通音频文件。

## 完成项

- Track 新增：
  - `cue_source: Option<PathBuf>`
  - `cue_start: Option<f64>`
  - `cue_end: Option<f64>`
- SQLite tracks 表新增对应列，旧库自动 `ALTER TABLE`。
- 扫描流程：
  - 同时收集 `.cue` 与音频文件；
  - 解析 CUE，音频存在时生成虚拟曲目；
  - 被 CUE 引用的音频文件不再作为单曲重复加入；
  - 无效 CUE 记录到扫描错误。
- 虚拟曲目：
  - 稳定 ID 由 CUE 路径 + 曲目号生成；
  - 标题、艺术家、专辑、音轨号来自 CUE；
  - 时长 = 起点到终点；
  - 最后一轨以音频实际时长结束。
- 播放：
  - 从 CUE `start` 开始；
  - 到达 CUE `end` 自动切下一首；
  - CUE 曲目禁用 gapless 预加载，避免越过轨道边界。

## 验证

- `cargo test --release`：35 passed，0 failed。
- 新增测试：
  - CUE 虚拟曲目边界与 ID；
  - 扫描器用 CUE 替换单文件音频，生成两首虚拟曲目。

## 已知限制

- CUE 曲目暂不支持单独编辑标签写入源文件。
- 封面/歌词仍按整个音频文件关联。
- 同一音频被多个 CUE 引用时只使用第一个。
