# RPlayer v2.0.15 — 空曲库与文件夹空态

日期：2026-11-25
分支：`feature/v2.0.15`

## 目标

空曲库不再是通用占位，而是两个明确状态：从未添加文件夹、已添加文件夹但没有音频。

## 范围

- 从未添加：主标题“把音乐放回桌面。”，唯一主动作“添加音乐文件夹”，说明只读本地文件。
- 已添加但无音频：标题“这个文件夹里没有音乐。”，主动作“重新扫描”，次动作“管理文件夹”。
- 显示支持格式与“不会删除磁盘文件”的说明。
- 扫描中状态保持原进度页。

## 验收

- 空曲库首次启动只有一个主按钮。
- 文件夹空态不再重复“添加音乐文件夹”，改为重新扫描/管理文件夹。
- `cargo test --release` 70 passed。
