# RPlayer v2.0.3 计划：对话框与工具窗口视觉收口

- 基线：`v2.0.2` / `6aca3a3`，70 tests
- 分支：`feature/v2.0.3`
- 目标：统一对话框与工具窗口的标题层级、字体与密度，补齐队列动效与边界状态

## 1. 范围

### P0 对话框

- 所有 11 个对话框共用 `dialog_header`：
  - 等宽小标题 `RPLAYER · DIALOG`
  - 23px 衬线标题
  - 11.5px 说明文字
- 保持 460px 基准宽度、10px 圆角、20px 内边距。
- 主操作在输入无效时禁用；关闭后焦点归还触发控件（v2.0.1 已实现）。

### P0 工具窗口

- 均衡器、曲库健康检查、智能歌单统一：
  - 等宽眉题 `EQUALIZER` / `LIBRARY HEALTH` / `SMART PLAYLIST`
  - 24px 衬线标题
  - 现有关闭按钮与右侧状态保持。
- 工具内部不重排，仅收敛标题层级，避免影响功能密度。

### P1 状态与动效

- 搜索无结果：图标、说明、清除按钮。
- 队列为空提示。
- 队列抽屉 280ms 滑入；对话框 140ms 淡入；页面 250ms 淡入。
- `减少动态效果` 时全部即时到位。

## 2. 实现文件

- `src/app/dialogs.rs`：`dialog_header` 改为眉题 + 衬线标题。
- `src/app/equalizer.rs`：`EQUALIZER` 眉题 + 24px 衬线标题。
- `src/app/health.rs`：`LIBRARY HEALTH` 眉题 + 24px 衬线标题。
- `src/app/smart.rs`：`SMART PLAYLIST` 眉题 + 24px 衬线标题。
- `src/app/player_bar.rs`：队列抽屉滑入（v2.0.2 已加入）。
- 版本：`Cargo.toml` → `2.0.3`。

## 3. 验收

- 1440×900 深色主题下，新建播放列表对话框标题为衬线、带 `RPLAYER · DIALOG` 眉题。
- 均衡器 / 健康检查 / 智能歌单标题为衬线且不与关闭按钮重叠。
- 1120×720 下对话框和工具窗口不裁切。
- `cargo test --release` ≥ 70。
- exe metadata `2.0.3.0`。

## 4. 已知限制

- 工具窗口内部控件仍沿用既有布局，本版只统一标题与边框，不重排 EQ 频段、健康检查分区或智能歌单规则行。
- 桌面歌词 DComp 双击解锁限制沿用 v2.0.2，正式解锁入口仍是设置页。
