# RPlayer v2.0.7 — 歌词编辑行距与锁定文案

基线：v2.0.6（`e5c0a8a`，70 tests，exe 2.0.6.0）
目标：修掉验收矩阵中两个低风险“部分”项，并关闭文案不一致。

## 1. 范围

1. 歌词编辑器行距从默认 10px 压到 6px，一屏可多显示 1–2 句。
2. 桌面歌词锁定提示统一为“已锁定 · 设置→桌面歌词 解锁”，与设置页入口一致。

## 2. 实现

- `src/app/lyrics_edit.rs`：滚动区 `ui.spacing_mut().item_spacing.y = 6.0`。
- `src/overlay.rs`：锁定提示文案改为 `已锁定 · 设置→桌面歌词 解锁`。
- 不改变歌词保存格式、时间解析、桌面歌词 DComp 结构。

## 3. 验收

- 1080p 下歌词编辑器可见行数增加，时间/文本输入不重叠。
- 锁定状态提示能直接指向设置页路径，不出现“双击解锁”。
- 桌面歌词 860×158、悬停面板、无歌词状态不回归。
- `cargo test --release` 70 passed；exe `2.0.7.0`。

## 4. 已知限制

- 自绘窗口顶边缩放仍未启用；尝试 6px 顶边热区会被标题栏拖动语义干扰，保持 `top=false`。
- 智能歌单规则行、桌面歌词菜单、离线/在线设置仍为“部分”。
