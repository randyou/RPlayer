# RPlayer v0.11.1 — 列表动效

## 目标

给侧栏导航和播放列表加入轻量 hover 过渡，不改变布局和选中逻辑。

## 完成项

- 导航项 hover 背景 120ms 淡入/淡出。
- 播放列表项 hover 背景 120ms 淡入/淡出。
- 选中项保持立即高亮，避免动画首帧造成“选中背景消失”。
- 动效受“减少动态效果”开关控制；开启后时长归零。

## 验证

- Release 构建通过。
- `cargo test --release`：29 passed，0 failed。
- 实机截图检查：
  - 当前视图「本地曲库」仍显示淡绿色选中背景；
  - 悬停「播放队列」显示 hover 背景；
  - 播放列表「深夜歌单」布局未变化。

## 暂缓

- 弹窗进入/退出动画。
- 主题切换颜色渐变。
- 列表行逐行动画。
