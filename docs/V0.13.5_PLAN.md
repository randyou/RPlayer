# v0.13.5 · 列表键盘导航与可访问性收尾

主题：把 v0.13.4 的“能 Tab 到”提升为“能高效浏览”，让歌曲列表成为真正的键盘工作区。

## 目标

- 歌曲表支持焦点行索引：`↑/↓`、`Home/End`、`PageUp/PageDown`。
- 焦点行自动滚入视口；切换视图后恢复上次焦点行。
- 统一搜索框与自绘控件的焦点描边。
- 歌曲行的 AccessKit 名称包含足够信息，重复歌曲也能唯一定位。
- 快捷键表补充列表导航说明。

## 实现

- `src/app/mod.rs`
  - 新增 `table_focus: Option<u64>`、`table_scroll_to: Option<usize>`、`table_restore: bool`。
  - `switch_view` 保留上次焦点曲目，并标记新视图需要恢复焦点。
- `src/app/library_view.rs`
  - 歌曲行改用稳定 `Id`：`ui.id().with(("track-row", track_id))`。
  - `table_target` 负责边界、翻页与首尾计算；`table_scroll_offset` 把目标行放到视口中央。
  - `show_rows` 前应用一次性滚动偏移，避免每帧强制滚动。
  - 焦点行 `Enter` 播放；行名称加入专辑、格式与完整路径。
  - 搜索框获得焦点时绘制 2px 主题色描边。
- `src/app/dialogs.rs`
  - 快捷键表增加列表导航三行。
- 单元测试：
  - `table_navigation_clamps_at_edges`
  - `table_paging_uses_page_size_and_clamps`
  - `empty_table_has_no_target`
  - `table_scroll_keeps_target_near_the_center`

## 验收

- 点击任意歌曲行后，`↑/↓` 逐行移动，`End` 到末行，`Home` 回首行。
- `PageUp/PageDown` 按当前视口行数翻页，并在边界处停住。
- 长列表中焦点行自动滚入视口；切换视图再返回时恢复原焦点行。
- `Enter` 播放当前焦点行，不依赖鼠标。
- AccessKit 能区分同名歌曲（名称含路径）。
- `cargo test --release`：59 passed。

## 已知边界

- 列表行使用应用级焦点索引；`Tab` 离开表格后方向键恢复全局 seek/音量语义。
- 自动滚动在 8 首曲库上只能验证不跳动；长列表滚动偏移由单元测试覆盖。
- 标准 egui 文本编辑框仍使用自身焦点样式，搜索框只补外圈描边。
- `Ctrl+A/O/N/E/L/M` 在控件拥有焦点时仍让位给控件；`Ctrl+K/F/,/T` 保留为全局入口。
