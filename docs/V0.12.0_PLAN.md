# RPlayer v0.12.0 — 重复歌曲查找

## 目标

开始 v0.12 曲库工具阶段，先提供安全的重复歌曲只读查找。

## 规则

- 歌名、艺术家按去空格、小写后比较；
- 时长相差不超过 2 秒；
- 不自动删除、不自动移动文件；
- 只展示分组、专辑、时长与路径。

## 入口

- 命令面板：`查找重复歌曲 · library.duplicates`
- 歌曲右键菜单：「查找重复歌曲…」

## 实现

- 新增 `src/duplicates.rs`：
  - `find(&[Track]) -> Vec<DuplicateGroup>`
  - 按歌名/艺术家分桶，再按时长聚类。
- 新弹窗 `Dialog::Duplicates`。
- 新增两个单元测试：
  - 正常分组并排除不同艺术家；
  - 唯一歌曲不误报。

## 验证

- Release 构建通过。
- `cargo test --release`：31 passed，0 failed。
- 实机命令面板打开「查找重复歌曲」：
  - 无重复时显示空状态；
  - 弹窗只有一个「关闭」按钮；
  - 布局与其它弹窗一致。

## 暂缓

- 重复项合并/删除。
- 音频指纹。
- 相似歌曲（不同版本/现场）。
