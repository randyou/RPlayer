# RPlayer v2.0.2 计划：桌面歌词与边缘状态

- 基线：`v2.0.1` / `b935e7b`，70 tests
- 分支：`feature/v2.0.2`
- 目标：补齐桌面歌词四态、空状态验收、对话框剩余细节与队列入场动效

## 1. 范围

### P0 桌面歌词四态

- 默认：860×158，透明背景，衬线浅色歌词，阴影保证亮壁纸可读。
- 悬停：深色半透明面板（alpha 0.78）、齿轮、锁定、关闭；面板内可拖动。
- 锁定：隐藏齿轮与关闭，保留锁定图标与“已锁定 · 在设置中解锁”；不可拖动。
- 无歌词：显示曲名、艺术家、“暂无歌词”与 LRC 提示。

验收：

- 窗口每轮打开都恢复 860×158，不沿用上次尺寸。
- 纸张主题下歌词仍为浅色；图标使用深色面板配色。
- 锁定状态持久化；解锁入口为设置 → 桌面歌词 → 锁定桌面歌词位置。
- 屏幕截图只用于视觉核对，DComp 透明窗口可能受桌面背景影响。

### P1 空状态与长文本

- 搜索无结果：图标、“没有找到匹配的歌曲”、清除按钮。
- 空曲库 / 空收藏 / 空队列沿用统一空状态组件。
- 长曲名、长专辑名、长文件夹路径使用截断 + AccessKit 完整名称。

### P1 对话框与动效

- 新建 / 重命名在名称为空时禁用主操作（v2.0.1 已实现）。
- 队列抽屉 280ms 右侧滑入；页面淡入保持 250ms；减少动态效果时直接到位。
- 对话框 140ms 淡入；关闭后焦点归还。

## 2. 实现

- `src/overlay.rs`：强制 Forest 调色板、固定尺寸、阴影、锁定 UI、空歌词提示。
- `src/platform/dcomp_panel.rs`：控制区命中转发；锁定状态不穿透到主窗口。
- `src/ui/icons.rs`：新增 Lock 图标。
- `src/app/player_bar.rs`：队列抽屉 `animate_bool_with_time` 滑入。
- 文档与 QA 截图：`docs/qa/v0.2/v202-*`。

## 3. 已知限制

- 桌面歌词是独立 DComp 透明窗口，双击解锁在部分合成路径下不可靠；正式解锁入口为设置页。
- 透明窗口的屏幕截图可能带桌面内容，不作为像素级验收依据。
