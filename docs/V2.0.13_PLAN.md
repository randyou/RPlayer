# RPlayer v2.0.13：标题栏拖动范围与窗口层级

## 问题

1. 标题栏只能按住面包屑和搜索左侧空白拖动，实际可抓取区域偏小。
2. 应用窗口会停留在其他程序之上，切换程序时遮挡对方。

## 实现

- 标题栏增加整宽上/下 10px 拖动带；保留面包屑、搜索左侧空白与顶部拖动带。
- 拖动带只覆盖空白区，按钮、搜索框、窗口按钮仍由控件优先接收点击。
- 根窗口显式设置 `WindowLevel::Normal`，不再使用测试时的 `HWND_TOPMOST`。
- 顶边仍只拖动、不缩放；左右/底边缩放不变。

## 验收

- 顶边 10px 内拖动可移动窗口；底部 10px 内拖动可移动窗口。
- 面包屑、搜索左侧空白可拖动。
- 主题、设置、窗口按钮点击正常。
- `GetWindowLongPtr(GWL_EXSTYLE)` 不含 `WS_EX_TOPMOST`；切换其他程序时本窗口不置顶。
- `cargo test --release` 70 passed。

## 发布

版本 `2.0.13`，分支 `feature/v2.0.13`，合并 `main` 后打 `v2.0.13`。
