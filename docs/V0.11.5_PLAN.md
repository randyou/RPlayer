# RPlayer v0.11.5 — 输入框焦点描边

## 目标

在不引入未验证的全局 Tab 焦点系统前，先让表单输入框有清晰可见的焦点反馈。

## 完成项

- `tag_field` 的文本框获得焦点时绘制 2px accent 描边。
- `name_field` 同样处理。
- 覆盖：
  - 编辑标签；
  - 批量标签；
  - 歌词匹配；
  - 新建/重命名播放列表。
- 焦点描边使用 `StrokeKind::Inside`，不改变输入框尺寸。

## 验证

- Release 构建通过。
- `cargo test --release`：29 passed，0 failed。
- 实机打开「新建播放列表」截图：
  - 名称输入框自动获得焦点；
  - 输入框四周显示绿色 accent 描边；
  - 弹窗布局和按钮位置未变化。

## 暂缓

- 全局 Tab 焦点顺序。
- 自定义导航/列表项焦点环。
- 主题切换渐变。
