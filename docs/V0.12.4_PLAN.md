# RPlayer v0.12.4 — 缺失文件重新定位

## 目标

让健康检查不仅能移除失效记录，还能把缺失曲目重新指向新文件。

## 完成项

- 健康检查「缺失文件」每条记录新增「重新定位…」。
- 打开系统文件选择器，仅接受支持的音频扩展名。
- 重新定位时：
  - 保留原曲目 ID；
  - 保留添加时间；
  - 保留收藏、播放次数、评分等按 ID 关联的数据；
  - 清除 CUE 虚拟曲目字段，避免错误边界。
- 重新定位后从当前健康报告移除该缺失项。
- 命令面板新增「曲库健康检查」入口。

## 验证

- Release 构建通过。
- `cargo test --release`：38 passed，0 failed。
- 新增测试 `relink_preserves_identity_and_clears_cue`。
- 实机命令面板打开健康检查，弹窗布局与关闭按钮正常。

## 暂缓

- 批量替换根目录。
- CUE 虚拟曲目单独重新定位。
- 自动搜索同名文件。
- 重新定位后的封面/歌词刷新策略。
