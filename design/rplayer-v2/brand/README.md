# RPlayer Brand · Sleeve R

RPlayer 的标识把“唱片套”与字母 R 合成一个形状：森林色方块是套，纸色几何 R 是封套里露出的字母。远看是 R，近看是套。

## 规则

- 色：forest `#2E5B44` + paper `#F4EFE5`。Nocturne 用 `#0F120F` 底 + reversed 组合。
- signal `#B64B31` 只用于状态（收藏、错误、退出），不进入标识。
- 标识最小 16px；横向字标 ≥ 12px；堆叠 ≥ 132px。
- 留白 `x = 1/4 标识宽`，四边不小于 x；标记内不放文字、线框或第二个标识。
- 不加投影、不用渐变、16–24px 不描边、深底必须反白。

## 字体

`RPlayer` 用 Noto Serif SC 600；`LOCAL LISTENING · 本地音乐` 用 Cascadia Mono。系统缺少 Cascadia Mono 时回退 Consolas，不嵌入字体。
