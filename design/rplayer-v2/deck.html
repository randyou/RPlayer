01 · 诊断 / WHERE IT HURTS

功能都在，
注意力不在。

BEFORE / RPLAYER 0.13.5 · 1202 × 812 · 原生标题栏 + 常驻右栏
01

七列，抢一条视线

曲目表同时塞进评分、格式、收藏、更多。每一列都在说话，于是没有一列被听见。

02

绿色，从按钮铺到歌词

高饱和绿同时用于主按钮、进度、标签和播放态。重点没有被分配，只是被重复。

03

面板在挤，内容在让

常驻右侧栏与原生标题栏一起吃掉宽度；窗口一小，曲目名先被截断。

04

六套主题，没有一套被记住

主题很多，但没有形成 RPlayer 的稳定气质。用户记不住它长什么样。

这次设计只做一件事：
让“正在听什么”成为界面的第一件事，其余信息退后半步。

03 · 本地曲库 / THE LISTENING PATH

曲目表不是数据库，
是一条聆听路径。

LOCAL LIBRARY / PAPER / 1440 × 900
01 / TITLE

一个页面，只出现一次衬线大标题

42px 只给“本地曲库”。曲名回到 13px，让标题重新拥有重量。

02 / COLUMNS

七列减到四列

删除评分与格式列，格式变成曲名后的一个 8px 徽标。专辑与时长足够定位。

03 / NOW

正在播放，三重但克制

左侧 2px 竖线、浅绿底、四格电平条。只在当前行出现，不与 hover 抢。

04 / RAIL

右栏只回答三个问题

封面是什么、词在哪、下一首是什么。其余动作收进“更多”和播放队列。

05 / CHROME

标题栏也是工作区

搜索、离线状态、主题、设置与窗口控制合并；拖动区域完整，不牺牲内容宽度。

01

五列封面墙 + 末尾导入卡。8 张专辑与“添加音乐”一屏放下，不再出现第二行被播放条裁掉。封面上的年份与厂牌是元数据，不抢标题。

02

歌单是“一张有封面的小唱片”。标题、总时长、播放动作先于曲目；侧栏用点数与数量，不用文件夹图标区分歌单与目录。

05 · 正在播放 / THE ROOM

正在播放，是一间房。

让窗口消失，
只剩下封面、词和声音。

NOW PLAYING / PAPERARTWORK 430
NOW PLAYING / NOCTURNELYRICS 32
FOCUS

封面 430px，标题 60px 衬线，歌词 32px。除当前行外全部降为暖灰。

LYRIC LINE

当前行只保留一条 14px 短线，不做彩色高亮块；滚动时不跳动。

NOCTURNE

不是把纸变黑：保留暖灰墨色与低饱和绿，让封面成为唯一亮面。

AMBIENCE

背景从封面取色，压到 6% 以内；暗角保证文字对比度始终 ≥ 7:1。

RPLAYER V2 · 06
06 · 交互 / KEYBOARD FIRST

键盘优先，鼠标其次。

COMMAND PALETTE / CTRL K
ONE ENTRY

Ctrl K 统一入口：曲目、专辑、页面、设置。输入即筛选，↑↓ 选择，Enter 执行，Esc 退出。

ONE SURFACE

队列是抽屉，不是第二套页面。当前曲、来源、播放模式在同一视线内；不打断主界面。

ONE DECISION

设置收成 6 个入口；主题只留两张卡；所有开关即时生效，不再有“应用 / 取消”。
