D / ANNOTATION KEY
1

状态默认 / 悬停 / 选中 / 播放 / 焦点，五种互不替代。

2

触发指针、键盘、右键、拖拽；同一结果允许多入口。

3

动效只写 transform / opacity；时长与曲线来自 tokens。

4

减弱系统 prefers-reduced-motion 或应用开关，全部 0ms。

IMPLEMENTATION NOTE “能看见的状态”必须可被读屏读出。

颜色变化不能是唯一信号：选中给 aria-selected，播放给 aria-current，错误给 role=alert。

STATE PRECEDENCE 焦点 > 选中 > 播放 > 悬停 > 默认

同一行只允许一种强调色；焦点环在最上层。

KEYBOARD PATH Tab · Space · ↑↓ · Enter · Esc

Esc 逐层退出，焦点回到触发控件。

TIMING BUDGET 90 / 140 / 280 / 520

超过 520ms 的动作不进入产品。

REDUCED MOTION 0ms · 无位移 · 无缩放

保留颜色与透明度；eq 冻结。
